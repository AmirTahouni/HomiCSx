# Support and maintenance

HomiCSx is research software maintained on a sustainability-oriented basis.
The current priority is a reproducible, citable core rather than continuous
feature development. Major correctness, reproducibility, and compatibility
problems may be addressed as maintainer availability permits, but response times
and future releases are not guaranteed.

Numerical-correctness, security, and reproducibility defects receive priority
over feature requests. The project does not promise a feature roadmap, support
for every new FEniCSx/Gmsh release, or an issue-response service-level
agreement. The versioned environment and archived releases are the long-term
reproducibility contract; community pull requests are welcome without a
guaranteed review time.

For reproducible bug reports and focused enhancement proposals, use the
[GitHub issue tracker](https://github.com/AmirTahouni/HomiCSx/issues). Include
the HomiCSx commit or version, operating system, environment details, a minimal
example, and the full error output. General FEniCSx installation questions are
best directed to the FEniCS Project's support channels.

The MIT License permits users and organizations to inspect, adapt, redistribute,
and fork the software. This is an intentional part of the project's continuity
plan if the original maintainer is unavailable.
