# Security policy

HomiCSx is scientific computing software and is not designed to process
untrusted input as a security boundary. Do not run untrusted Python hooks,
meshing scripts, or model files.

Please report a suspected vulnerability privately through GitHub's security
advisory interface for this repository. If that interface is unavailable,
contact the maintainer using the address in `CITATION.cff`. Avoid publishing
exploit details before the report has been assessed.

Security fixes are considered for the latest source version as maintainer
availability permits. No guaranteed response time or long-term-support branch
is offered.
